# Spatial Blueprint MR

A Unity and C# prototype by Ravanna Bell III that converts architectural DXF drawings into life-size 3D wall models.

Features include line and polyline parsing, wall-layer filtering, unit conversion, wall meshes with colliders, calibration, placement controls, and local save/load.

Current scope: desktop and Unity Editor prototype. Headset interaction and room anchors remain planned.

Open in Unity 6.6, resolve packages, and select Tools > Spatial Blueprint MR > Create Unity 6 Starter Scene. Save the scene and press Play.
