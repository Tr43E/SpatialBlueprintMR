Spatial Blueprint MR

From architectural floor plans to life-size 3D walls. A Unity and C# prototype for exploring building layouts in three dimensions.

C#UnityDXF parsing3D geometry
View project on GitHub · Explore the implementation ↓
DXF drawing → Entity and layer parsing → Unit conversion → 3D wall meshes → Calibration and placement

What it does

  • Parses ASCII DXF lines and polylines and filters wall layers.
  • Converts drawing units to meters and generates wall meshes with colliders.
  • Supports movement, rotation, elevation, scale calibration, and placement locking.
  • Saves and restores placement locally.

How it is built

The parser reads drawing geometry and units. The importer selects wall geometry, the model generates the meshes, and a placement controller manages calibration and saved transforms.

Separating these responsibilities keeps the drawing format, geometry generation, and interaction logic independently understandable.

Current scope and next steps

The current prototype provides desktop and Unity Editor controls. Headset controller interaction, two-hand manipulation, and persistent room anchors are next steps; this page does not represent a completed headset deployment.
