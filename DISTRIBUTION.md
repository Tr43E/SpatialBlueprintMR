# Sharing the Windows demo

In Unity, choose **Tools > Spatial Blueprint MR > Build Windows Release**. The project creates a timestamped folder and matching `.zip` file in `Builds`.

Share the generated `.zip`, not the `.exe` by itself. Testers unzip it and run `SpatialBlueprintMR.exe`; Unity does not need to be installed on their PC. The build includes the demo scene and all files in `Assets/StreamingAssets`, including the studio, apartment, and office DXF samples.

For GitHub, upload the generated ZIP to a GitHub Release and link it from the repository README or portfolio page.
